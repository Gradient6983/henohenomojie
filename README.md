# へのへのもじ絵

**日本語** | [English](./README.en.md)

歌詞の文字を一つひとつ適切な大きさと色で配置し、最終的に文字だけで一枚の絵を描き出すことを目指したプロジェクトです。

## コンセプト

- 適切な数の文字をキャンバスに表示します。
- 最初に置く文字は大きく、その後に置く文字はだんだん小さくして、「背景 → ディテール」の順で絵を構成します。
- まずランダムな位置で複数の候補を生成し、それを空のテクスチャに描いて元画像と比較し、スコアを記録します。文字の色は、文字が重なる画像ピクセルの平均色から自動で決まります。
- 上位 n 個の候補を抽出し、位置や大きさなどの値に少しずつ variance を加えて変化させます。
- 「上位候補の抽出 → 変化」を何度も繰り返し、最終的に最適な位置と大きさの文字を選びます。
- 確定した文字はそのテクスチャに焼き込み、次の文字はその上に重ねて再び比較します。

## 技術スタック

- **Svelte 5**（runes 構文）+ **Vite** ベースの SPA
- **TypeGPU / WebGPU**: 文字位置の探索と画像比較の演算
- **PixiJS 8**: 抽出した文字配置のキャンバスレンダリング
- **TextAlive App API**: 歌詞・タイミングデータの抽出とリアルタイム再生制御
- **自前の軽量 i18n モジュール**（`src/i18n`）: 多言語 UI 文字列の管理（外部ライブラリなし）。既定言語は日本語で、日本語・韓国語・英語に対応します。

## 画面構成

`src/main.ts` が `src/lib/Root.svelte` をマウントし、URL パスを使わずコンポーネントの状態で 2 つの画面を切り替えます。

| 画面        | コンポーネント           | 役割                                            |
| ----------- | ------------------------ | ----------------------------------------------- |
| `home`      | `PixiPreviewPage.svelte` | 曲の選択・紹介画面 → 選んだ曲を音楽に合わせ再生  |
| `workspace` | `UploadTrainPage.svelte` | 画像アップロード + 曲選択 → 文字配置の学習を実行 |

`home` で「自分で学習」を押すと `workspace` へ移動し、学習を終える（`onPlay`）と `home` に戻って、学習したばかりの曲を自動再生します。

主な機能は次のとおりです。

- **曲選択・再生**（`PixiPreviewPage` → `GlyphPlayer`）: 曲カードを並べ、選んだ曲を TextAlive Player で音楽に同期して再生します。文字は登場アニメーションとパーティクル（花火）付きで現れ、星座モードや輪郭線オーバーレイなどの表示効果も設定できます。
- **アップロード・学習**（`UploadTrainPage` → `GlyphTrainer`）: 画像をアップロード（またはサンプル選択）して曲を選び、「画像準備 → 歌詞抽出 → 学習 → 仕上げ → 完了」のパイプラインを実行します。途中でいつでもキャンセルできます。
- **多言語 UI**（`src/i18n`）: UI 文字列をコンポーネントから分離し、`t()` で参照することで言語切り替え時に自動で再描画されます。

## ディレクトリ構成

```
src/
├─ const/      # 変化しない定数（テクスチャ設定・曲カタログ・API トークンなど）
├─ types/      # 共通の型定義
├─ stores/     # グローバル状態（モジュールシングルトン）
├─ util/       # 汎用ユーティリティ（math / color / time / 画像 / 文字キャンバスなど）
├─ pixijs/     # PixiJS ヘルパー（tint / テクスチャ / 花火パーティクル）
├─ textAlive/  # TextAlive 関連ロジック（歌詞抽出 / JSONL シリアライズ）
├─ i18n/       # 多言語 UI 文字列（messages / locale / index）
├─ assets/     # 曲画像・輪郭線画像・歌詞データ（jsonl）
├─ webgpu/     # WebGPU/TypeGPU の演算（候補生成・比較・色計算・Sobel など）
└─ lib/        # 画面（Svelte コンポーネント）と共通 UI コンポーネント
```

## JSONL データフォーマット

1 行につき 1 つの JSON レコードで、`type` フィールドで区別します。あらかじめ抽出された曲は `src/assets/*.jsonl` としてバンドルされ、自分で学習すると同じフォーマットの文字列がメモリ（`trainedStore`）に生成されます。

- `song`: 曲のメタデータ（タイトル、アーティスト、duration、全歌詞など）
- `phrase`: 歌詞のフレーズ単位のテキストと開始・終了時間
- `word`: 単語単位のテキストと時間
- `char`: 文字単位のテキスト、時間、レンダリング可否
- `placement`: 抽出された文字の配置情報
  - `step`: 表示順
  - `char`: 文字
  - `pos`: `{ x, y, scale, opacity, rotation }`（x/y は 0〜1 の正規化座標）
  - `color`: `[r, g, b]`（各 0〜1）
  - `diff`: その配置の差分スコア

再生画面ではこのうち `placement` / `char` / `phrase` / `song` を使い、文字は `step` 順にレンダリングされます。

## 実行方法

### 必要なもの

- **Node.js 20.19 以上**（または 22 以上）と **pnpm** — Vite 8 の動作要件です。`node -v` で確認できます。pnpm が未インストールの場合は `npm install -g pnpm` か `corepack enable pnpm` で導入できます。
- **WebGPU 対応ブラウザ**（最新版の Chrome / Edge など）— 学習機能に必須です。
- TextAlive App API トークンは `src/const/textAlive.ts` に同梱済みのため、追加設定は不要です。

### クイックスタート（開発サーバー）

```bash
# 1. リポジトリを取得
git clone <このリポジトリのURL>
cd typegpu-glyph

# 2. 依存関係をインストール
pnpm install

# 3. 開発サーバーを起動
pnpm dev
```

起動後、ターミナルに表示される URL（既定は http://localhost:5173/ ）をブラウザで開きます。

### その他のコマンド

```bash
# 型 / Svelte チェック
pnpm check

# 本番ビルド（dist/ に出力）
pnpm build

# ビルド結果をローカルでプレビュー
pnpm preview
```

### 使い方

1. ホーム画面で曲を選んで再生するか、「自分で学習」を押して学習画面へ進みます。
2. 学習画面では画像をアップロード（またはサンプルを選択）し、曲を選んで学習を実行します。
3. 学習が完了すると自動的にホームへ戻り、学習したばかりの曲が再生されます。

> 学習機能を正常に動かすには、WebGPU に対応したブラウザ（最新版の Chrome や Edge など）で実行してください。非対応の環境でも、ホーム画面とバンドル済みの曲の再生は可能です。
